## Detailed description

Highlight any text on any page, fire a keyboard shortcut or right-click, and XTHIS opens a new X post pre-filled with the quote and the page URL. One step. No copy-paste, no tab juggling, no "wait, where was that from again?"

**How it works**

1. Select text on any web page.
2. Trigger XTHIS — toolbar icon, right-click menu, or keyboard shortcut.
3. A new tab opens at X's post composer with `"your selection" page-url` ready to go.
4. Edit if you want. Hit Post.

If nothing is selected, you get the page URL alone — handy for sharing an article you haven't read yet.

**Keyboard shortcuts**

- Control + Shift + X
- Option + Shift + X

Rebind either at chrome://extensions/shortcuts if they collide with something on your machine.

**What XTHIS does not do**

- No accounts, no logins, no API keys — uses your existing X session.
- No tracking, no analytics, no telemetry.
- Nothing leaves your browser except the post composer URL you click into.

Selections longer than 254 characters are trimmed with a single ellipsis so the quote + URL fit X's 280-character limit (the URL counts as 23 characters once X wraps it).

Internal pages (chrome://, file://, etc.) are silently skipped.
