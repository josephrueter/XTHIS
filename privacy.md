# XTHIS — Privacy Policy

_Last updated: 2026-05-27_

XTHIS is a Chrome extension that opens X.com's post composer pre-filled with text you have selected and the URL of the page you're on. This is its single purpose.

## What XTHIS collects, uses, and shares

- **Collects:** nothing. XTHIS does not gather any personal information, browsing history, page content, or selected text into any developer-controlled storage or server.
- **Uses:** when you trigger XTHIS, it reads — locally, inside your browser — the text you have selected and the URL of the active tab. It uses these only to build a single `x.com/intent/post` link and open it in a new tab.
- **Shares:** nothing with the developer. When you click into the X composer, X.com receives the link the same way it would if you typed the URL yourself.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Permissions

- `activeTab` — to read the URL and the selected text of the tab you're on, only at the moment you trigger XTHIS.
- `contextMenus` — to add the "Post to X with XTHIS" right-click entry.
- `scripting` — to read the current selection from the active tab.

XTHIS does not request any other permissions and does not read any tab other than the active one at the moment you trigger it. It does not handle your X.com login — it relies on the session already in your browser.

## Children's privacy

XTHIS is not directed at children under 13 and does not knowingly collect any information from them. (It does not knowingly collect any information from anyone — see above — but stating it explicitly here is required.)
